# Visage Clinic

A modern, responsive aesthetic clinic website built using HTML, CSS, and JavaScript.

## 🌐 Project Overview

Visage Clinic is a professional frontend website designed for an aesthetic and dermatology clinic. The project focuses on a clean visual experience, responsive design, treatment information, doctor profiles, and appointment navigation.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern aesthetic clinic user interface
- Homepage with premium hero section
- Doctor profile pages
- Clinic information pages
- Appointment page
- Multiple treatment detail pages
- Skin and hair treatment categories
- Custom navigation and interactive elements
- SEO files including `robots.txt` and `sitemap.xml`
- Custom 404 error page
- Netlify deployment configuration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git
- GitHub
- Netlify
